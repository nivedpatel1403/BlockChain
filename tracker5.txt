EXPERIMENT 5: CRYPTOCURRENCY FOR MULTIPLE USERS USING PYTHON
AIM: Build CLI cryptocurrency wallet simulating wallet mgmt, transactions, gas
fees, and blocks using a local simulated blockchain (web3.py EthereumTesterProvider).
REQUIREMENTS: Python 3.8+, pip package `web3[tester]`, terminal.
SETUP:
1. Create+activate venv:
   Windows: `mkdir BlockchainLab && cd BlockchainLab` ; `python -m venv venv` ;
   `.\venv\Scripts\activate`
   Linux/macOS: `mkdir BlockchainLab && cd BlockchainLab` ; `python3 -m venv venv` ;
   `source venv/bin/activate`
2. Install deps: `pip install "web3[tester]"`
3. Create file `wallet_shell.py` with code below.
CODE (wallet_shell.py):
```
import sys
import cmd
from web3 import Web3

class WalletShell(cmd.Cmd):
   intro = 'Welcome to the ClassCrypto Shell. Type help or ? to list commands.\n'
   prompt = '(crypto) > '

   def __init__(self):
     super().__init__()
     self.w3 = Web3(Web3.EthereumTesterProvider())
     self.accounts = self.w3.eth.accounts
     self.users = {
        "bank": self.accounts[0],
        "alice": self.accounts[1],
        "bob": self.accounts[2],
        "charlie": self.accounts[3]
     }
     print(f"Blockchain initialized with {len(self.users)} users: Bank, Alice, Bob, Charlie")

   def do_balance(self, arg):
     name = arg.lower().strip()
     if name not in self.users:
        print(f"Error: User '{name}' not found. Available: {list(self.users.keys())}")
        return
     address = self.users[name]
     wei_balance = self.w3.eth.get_balance(address)
     eth_balance = self.w3.from_wei(wei_balance, 'ether')
     print(f"User: {name.capitalize()}")
     print(f"Address: {address}")
     print(f"Balance: {eth_balance} ETH")

   def do_send(self, arg):
     args = arg.split()
     if len(args) != 3:
         print("Error: Usage is 'send <from> <to> <amount>'")
         return
     sender, receiver, amount = args[0].lower(), args[1].lower(), args[2]
     if sender not in self.users or receiver not in self.users:
        print("Error: Unknown user. Please use: bank, alice, bob, charlie")
        return
     try:
        amount_eth = float(amount)
        sender_addr = self.users[sender]
        receiver_addr = self.users[receiver]
        print(f"Processing transaction: {sender.capitalize()} -> {receiver.capitalize()} ({amount_eth} ETH)...")
        tx_hash = self.w3.eth.send_transaction({
           'from': sender_addr,
           'to': receiver_addr,
           'value': self.w3.to_wei(amount_eth, 'ether')
        })
        receipt = self.w3.eth.wait_for_transaction_receipt(tx_hash)
        print(f"Success! Block #{receipt.blockNumber} mined.")
        print(f"Gas Used: {receipt.gasUsed} (Cost to process)")
        print(f"Tx Hash: {tx_hash.hex()}")
     except ValueError as e:
        print(f"Transaction Failed: {e}")
     except Exception as e:
        print(f"System Error: {e}")

   def do_chain(self, arg):
     latest = self.w3.eth.get_block('latest')
     print("\n--- LATEST BLOCK ---")
     print(f"Block Number: {latest.number}")
     print(f"Block Hash: {latest.hash.hex()}")
     print(f"Transactions: {len(latest.transactions)}")
     print("--------------------")

   def do_exit(self, arg):
     print("Closing connection...")
     return True

if __name__ == '__main__':
   try:
      WalletShell().cmdloop()
   except KeyboardInterrupt:
      print("\nExiting...")
```
KEY TOOLS: Web3.py = bridge translating Python calls to JSON-RPC for blockchain
nodes. EthereumTesterProvider = simulated in-RAM blockchain (auto mining/signing/
gas), disappears on script close. `cmd` module = builds interactive shell w/ prompt.
PROCEDURE (walkthrough):
1. Run `python wallet_shell.py` -> shows welcome + `(crypto) >` prompt.
2. `balance bank` -> record hex address + balance (starts ~1,000,000 ETH test funds).
3. `balance alice` -> also starts ~1,000,000 ETH.
4. `send bank alice 50.5` -> observe Block # mined, Gas Used, Tx Hash.
5. `balance bank`, `balance alice` again -> verify ledger updated.
   Q: Bank loses exactly 50.5 ETH or 50.5+gas? (Gas fee makes it slightly more,
   though in this tester provider gas is separate from the 'value' sent).
6. `chain` -> inspect latest block (number, hash, tx count).
7. (Optional) `send alice bob 2000000` (more than Alice has) -> Python/web3
   raises error; blockchain logic rejects invalid state transition (double-spend
   prevention).
RESULT: CLI multi-user cryptocurrency wallet built & tested on simulated chain.
VIVA: Wallet = identified by address; Gas = fee to process tx on network; Double-
spend prevention = network rejects tx if sender balance insufficient.
